Executes bash commands in persistent shell. For terminal ops (git, npm, docker), not file ops (use Read/Write/Edit/Grep/Glob).

Runs in ${directory}. Use `workdir` param to change, not `cd &&`.
Quote paths with spaces. Timeout: 120s default.
Large output truncated - use Read/Grep to view full content.
Avoid: find, grep, cat, head, tail, sed, awk, echo.
Multiple commands: parallel if independent, && if dependent, ; if failures ok.

Committing: git status, git diff, analyze, draft message (why not what), add files, commit, verify
PRs: git status, git diff, check remote, git log, diff base...HEAD, analyze ALL commits, branch if needed, push -u, gh pr create
Never use -i flag (interactive unsupported)
